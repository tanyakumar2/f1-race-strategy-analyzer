# F1 Race Strategy Analyzer

A Python project for analyzing Formula 1 race strategy using real race data.

## Project Goals

The project will eventually:

- Reconstruct driver tire strategies by stint
- Analyze representative stint pace and tire degradation
- Compare the strategies of two drivers
- Examine undercuts and overcuts
- Estimate alternative pit-stop strategies
- Visualize tire strategies and lap-time trends

## Planned Technologies

- Python
- FastF1
- Pandas
- Matplotlib

## Project Status

This project is currently in development. The first milestone is loading and inspecting data from a Formula 1 race.
